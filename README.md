Excited to share my HR Analytics Dashboard, created using Power BI! 

The goal of this project was to analyze employee data and transform it into meaningful insights that can support better HR decision-making.

📌 Key Insights Covered:
🔹 Total Employees & Active Employee
🔹 Employee Attrition Analysis
🔹 Employee Service Years
🔹 Attrition Count by Education Field
🔹 Employee Count by Ege Group
🔹 Job Satisfaction Rating
📈 Through this project, I explored how interactive dashboards can help HR teams understand workforce trends, monitor employee metrics, and make data-driven decisions.
💡 Key Learnings: Data visualization, KPI analysis, dashboard design, and translating raw data into actionable insights.
